## [0.1.0] - 2026-09-20

### Added
- Initial release of Engli
- Lexer with full token system
- Parser with complete grammar
- AST with source location tracking
- Semantic analyzer
- Interpreter with direct AST execution
- Runtime value system
- Standard library (core, io, filesystem, process, environment, http, json, time, random, concurrency)
- Module system with imports and exports
- REPL with multiline support and commands
- Formatter
- Comprehensive error diagnostics
- CLI with all commands
- Complete test suite
- Documentation
- Example programs
