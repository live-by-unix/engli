The language

English-like.
Actually powerful.

Engli keeps the syntax readable while providing the building blocks you'd expect from a real programming language.

◈

English-like syntax

Write code that reads naturally. Commands such as Set, Say, If, and While are immediately understandable.

∞

Turing-complete

This isn't a toy syntax. Engli supports the control flow, data structures, functions, and runtime features needed for general-purpose programming.

λ

Functions

Define reusable functions with readable declarations, arguments, return values, and normal program structure.

▦

Rich data structures

Work with lists, maps, objects, custom types, and enumerations directly in the language.

↗

Real-world I/O

Engli can work with files, terminal commands, HTTP, JSON, and imported modules.

⚡

Concurrency

Start tasks and wait for them to finish using readable concurrency primitives.

Readable by design

Code that explains itself.

Engli uses a deterministic grammar while keeping its programs approachable. You shouldn't need to decode punctuation before understanding what the program does.

example.engli
Set name to "AB".
Set age to 20.

If age is greater than or equal to 18:

    Say "Hello, {name}.".
A tiny taste

It looks like English.

But underneath, Engli has a lexer, parser, semantic analyzer, interpreter, runtime, and standard library.

Command line

One command to run it.

Install Engli, write a program, and run it directly.

terminal 
$ python3 -m venv .venv
$ source .venv/bin/activate
$ pip install -e .
$ engli hello.engli

Hello, World.

$ engli repl

Engli REPL 1.0.0
> Set x to 10.
> Add 5 to x.
> Say x.
15
